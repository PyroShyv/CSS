Estudo CSS

Alterações nas estéticas da página web

CSS (Cascading Style Sheets) é uma linguagem usada para definir a apresentação e o layout de documentos HTML ou XML. Ela permite separar a estrutura do conteúdo da aparência visual de um site, proporcionando mais controle sobre o design, cores, fontes e disposição dos elementos. A principal vantagem do CSS é que ele permite a aplicação de estilos em múltiplas páginas de um site a partir de um único arquivo, facilitando a manutenção e atualização do design.
